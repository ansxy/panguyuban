Modular provider adapters

Panguyuban separates Rust traits in panguyuban-core from platform adapters so you can swap Plane.so or GitHub without touching the UI.

IssueProvider trait

Active: provider-plane

Connects ticket queues, state transitions, and cycle metadata to the Tauri frontend.

Available trait implementations: provider-plane, provider-linear, provider-jira.
Stored in local SQLite configuration; API token sits in OS keychain.

GitProvider trait

Active: provider-github

Manages pull request review queues, CI status checks, local git2 branches, and squash merges.

Available trait implementations: provider-github, provider-gitlab, provider-gitea.
Matched against ticket IDs via branch pattern feat/pan-* and fix/pan-*.
